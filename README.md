# 사이버 추모관 (MP-cyber)

일상 속 추모와 디지털 기록저장소를 제공하는 Next.js 웹 서비스입니다.

## 기능
- 디지털 추모관 (3D 추모실, 영상, 추모글, 추억앨범)
- 디지털 기록저장소 (생애주기별 기록, 100MB, 3년)
- 관리자 (추모관/콘텐츠 관리)

## 로컬 실행
1. `.env.local`에 `MONGODB_URI`, `ADMIN_PASSWORD` 설정
2. `npm install`
3. `npm run dev`

## 배포 (Render)
- GitHub `hanbaedal/MP-cyber` 연결
- 환경변수: `MONGODB_URI`, `ADMIN_PASSWORD`, `ADMIN_SECRET`
